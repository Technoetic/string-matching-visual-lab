문자열 매칭 비주얼 랩

긴 글에서 패턴을 찾는 알고리즘을, 글자 칸이 움직이는 애니메이션으로 직접 배워 보세요.

브라우저에서 Ctrl+F를 누르고 단어를 입력하면, 컴퓨터는 긴 텍스트(haystack) 안에서 짧은 패턴(needle)이 어디 있는지 찾습니다. 카카오톡 검색, 코드 에디터의 찾기, grep, 자동완성, 심지어 DNA 서열 분석까지 — 모두 같은 “문자열 매칭” 문제예요. 아래에서 텍스트와 패턴을 직접 바꿔 가며 ▶ 버튼으로 한 단계씩 따라가 보세요.

이 알고리즘들은 어디에 쓰일까요?

  • 브라우저·문서의 Ctrl+F 페이지 내 찾기
  • 메신저(카카오톡·슬랙) 대화 검색, 코드 에디터의 Find / grep·ripgrep
  • 검색창 자동완성(접두사 매칭), 표절 검사·침입 탐지(해시 기반)
  • 생물정보학의 DNA 서열(A·C·G·T) 검색
